# 🚀 Nivelamento: HTML & CSS Essencial

> **Objetivo:** Proporcionar uma preparação ágil e pragmática nos pilares do HTML e CSS, construindo a base necessária para você avançar rapidamente rumo aos **frameworks e bibliotecas front-end modernos** (como React, Vue, Angular, Next.js, Tailwind, etc.).

---

## 📌 Sobre este Repositório

Este repositório **não tem como objetivo ser um curso exaustivo, uma imersão profunda ou um manual de referência com índice remissivo** cobrindo todas as tags e propriedades existentes na Web.

O foco aqui é o **pragmatismo**: abordar os conceitos essenciais que aparecem em 90% do dia a dia do desenvolvimento web, permitindo que você domine a estrutura e a estilização básica sem perder tempo, estando pronto para focar no aprendizado das ferramentas modernas de mercado.

---

## 🎯 Conteúdo em Destaque

* **HTML Semântico Essencial:** Estruturação correta de páginas e acessibilidade básica.
* **Box Model & Estilização:** Compreensão de margens, espaçamentos, bordas e dimensionamento.
* **Layouts Modernos:** Princípios práticos de **Flexbox** e **CSS Grid** para organizar componentes.
* **Responsividade Básica:** Conceitos essenciais de *media queries* e adaptação de layouts.

---

## 🛑 O que você NÃO vai encontrar aqui

* ❌ Um índice remissivo/dicionário completo de todas as tags HTML e seletores CSS.
* ❌ Aprofundamento em técnicas legadas (como layouts com *floats* ou tabelas).
* ❌ Efeitos visuais complexos ou animações puras avançadas que fogem do uso rotineiro de componentes.

---

## 💡 Para quem é este repositório?

Para desenvolvedores e estudantes que precisam **nivelar o conhecimento de forma rápida e eficiente**, eliminando lacunas na base web para entrar com confiança no ecossistema de frameworks front-end.
